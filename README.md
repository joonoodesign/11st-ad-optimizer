# 11st-ad-optimizer (주누디자인 11번가 포커스클릭 & 스토어 SEO 최적화 대시보드)

11번가 광고센터(AD OFFICE) 포커스클릭 캠페인/그룹 입찰 전략, 제외키워드(Negative Keywords) 관리, 그리고 스토어 전 상품(8종) 맞춤 SEO 상품명·검색태그(20개)·쿠폰/즉시할인 품질지수 최적화를 아이폰(iOS)·아이패드(iPadOS)·PC 어디서나 365일 24시간 실시간으로 관리하는 반응형 PWA 웹 애플리케이션입니다.

## 🌐 배포 주소 및 클라우드 아키텍처
- **GitHub Pages (24시간 무료 HTTPS 호스팅)**: `https://joonoodesign.github.io/11st-ad-optimizer/`
- **실시간 클라우드 DB 동기화**:
  1. **GitHub REST API (`db-store` 브랜치 `data.json`)**: PC·아이폰·아이패드 간 양방향 실시간 데이터 동기화 및 카카오톡 원클릭 자동 연결 링크(`#ghSync=...`) 지원 (저장소 내 토큰 노출 방지)
  2. **Google Drive + Google Apps Script 연동 (`google_drive_db.gs`)**: 내 구글 드라이브에 JSON 데이터베이스를 직접 백업·복원할 수 있는 연동 옵션 동시 제공

## ✨ 주요 기능 (4대 핵심 탭)
1. **📊 종합 효율 & 지면 분석 (Overview)**
   - 총 잔액(`60,371원`), 최근 7일 노출(`1,747회`)·클릭(`5회`, CTR `0.29%`), 운영중 상품(`8/8개`), 단가/할인 상태(`할인 미적용 · 1,000원 단가 수량 결제 방식 유지`) 실시간 KPI 요약
   - **검색 지면(CTR 0.68%) vs 추천 지면(CTR 0.21%, 노출 83.2% 편중)** 비교 진단 및 **입찰가 이원화(검색 250원 상향 / 추천 90원 최저가 하향)** 시뮬레이터
   - 오늘(2026-10-20) 실제 적용 완료된 5대 광고·SEO 최적화 체크리스트
2. **🏷️ 전 상품(8종) SEO 상품명 & 태그 관리**
   - 주누디자인 11번가 스토어 판매중 8개 전 상품(`9578004524`, `2374828642`, `2402731821`, `2485520536`, `7798910249`, `3352710339`, `3529699389`, `4877400502`)의 변경 전후 상품명 및 검색태그 20개 관리
   - 상품명 실시간 편집·저장 및 **원클릭 클립보드 복사(상품명 복사 / 검색태그 20개 복사)**
3. **🔍 키워드 성과 & 제외키워드 센터**
   - 실제 노출된 31개 키워드/지면 전체 성과 데이터 필터링(고효율 핵심어 / 순위개선 필요 / 제외키워드 차단 / 추천지면) 및 CSV 다운로드
   - 오인 노출 차단 **제외키워드(Negative Keywords) 9종**(`맞춤가구`, `주문제작가구`, `포인트가구`, `deco그레이`, `데코`, `시티지인테리어`, `스티커제작기계`, `장애이해스티커주문제작`, `트럭용스티커제작`) 추가·삭제 및 AD OFFICE 붙여넣기용 줄바꿈 복사
4. **🎯 캠페인 & 입찰 전략 관리**
   - `01_캠페인(간편등록)`(`615540`) → `01_그룹`(`2879183`) 입찰가 설정 및 11번가 포커스클릭 품질지수(견적결제 단가 유지 + 8종 전 상품 운영 + SEO 상품명 + 제외키워드) 100점 진단기

## 📱 모바일 앱 설치 방법 (PWA)
- **아이폰 / 아이패드 (Safari)**: 접속 후 하단 공유 버튼(`[↑]`) → **`[홈 화면에 추가]`** 터치
- **PC / 안드로이드 (Chrome/Edge)**: 주소창 우측 **`[앱 설치]`** 아이콘 클릭
